# sanjiu-evolve · 三九·创作进化

版本：0.2.1。员工复制下面一句话即可开始；遇到问题看 **[员工上手指南](员工上手指南.md)**，验证范围见 [检查报告](CHECKS.md)。

从真实项目与反馈中积累方法，帮助 AI 理解客户需求，写出更符合项目的脚本与提示词。

第一版采用 Sanjiu 已在实际工作中使用、持续修正的创作方法。先把这一套用好，暂不拆成“个人版”和“通用版”。这些是可调整的工作默认，不是所有创作者都必须遵守的标准；具体客户要求和本次明确决定优先。

## 员工从这里开始

打开能联网并处理本机文件的 AI（例如 Codex），发送这一句话；安装、配置和检查交给 AI：

```text
请从 https://gitee.com/the-third-nine/sanjiu-evolve （打不开时用 https://github.com/sanjiu-byte/sanjiu-evolve ）安装并配置 sanjiu-evolve，让我以后每个项目默认使用它、自动维护各项目的本地经验，并自行检查是否配置成功。
```

等 AI 报告配置结果，就可以正常说项目需求，例如：“这是新品介绍项目，根据这些客户要求写一版15秒脚本。”不用每个项目重复安装或再说一遍启用口令。暂时没有项目也能先完成用户级配置；以后首次真正处理项目时由 AI 接入。

**给收到这句话的 AI：**先读本仓库的 [SKILL.md](SKILL.md) 和 [首次启用](references/首次启用.md)，按使用者明确要求实际下载、配置、读回并自检，不把安装教程再交还员工。既有配置与私人记录保留，项目资料不上传。只说“下载”且未表达安装启用意图时，不自行扩展为修改全局默认。

这适用于具备相应能力和权限的 AI 工具。工具弹出必要权限提示时，员工可能需要点允许；确实要求新聊天才能加载时，AI 应只告诉员工这一个下一步。只能聊天、不能写文件的环境使用附件模式，不能做到自动本机配置。备用仓库：[GitHub](https://github.com/sanjiu-byte/sanjiu-evolve)。

**权限或连接问题、日常纠正、换聊天与换电脑，见 [员工上手指南](员工上手指南.md)。这些是备用说明，不是员工必须先完成的一套操作。**

## AI 收到这套方法后做什么

| 时机 | 应完成的事 |
| --- | --- |
| 第一次启用 | 按 [首次启用](references/首次启用.md) 核对工具能力、配置本机入口，并说明真实完成度 |
| 每个项目开工 | 找当前项目已有规则与记录，只把适用的方法带进来 |
| 员工指出问题 | 先修成果；按已有授权沉淀明确可复用的纠正，不要求每次提醒“记住” |
| 新聊天或分支继续 | 重新核对入口、最新任务及例外，用成果体现已经落实 |

这套工作流程适用于后续各项目；运镜、表演和时长等创作细则只用于创作任务。普通闲聊不建立项目台账。只读附件的聊天可使用手动保存模式，不能据此声称完成跨项目自动接入。

Codex 的本机技能发现和全局入口需要按实际配置核对，具体做法交给 AI 阅读 [首次启用](references/首次启用.md)。安装与配置不代表全部已打开聊天立即重新加载；新聊天自检步骤在员工指南中。

## 包里有什么

| 文件 | 用途 |
| --- | --- |
| [SKILL.md](SKILL.md) | AI 的工作入口 |
| [员工上手指南](员工上手指南.md) | 从首次设置到日常项目的可复制操作步骤 |
| [首次启用](references/首次启用.md) | AI 安装、跨项目入口和当前项目接入的执行规程 |
| [创作方法](references/创作方法.md) | 需求边界、表达、运镜、节奏、参考映射和交付默认 |
| [经验与接续](references/经验与接续.md) | 从纠正中积累、读取相关经验、恢复当前任务 |
| [项目记录模板](references/项目记录模板.md) | 没有现成记录时可复制的空白示例 |

优先复用项目已有记录。没有时，可在使用者的项目内使用 `.local/sanjiu-evolve/`，先确认该目录被版本控制忽略且未被跟踪，再保存真实内容。这个仓库只放方法和空白模板，不把客户资料、私人聊天、原始素材或本机配置放进来；私有仓库也不等于获得了这些资料的上传授权。

本仓库采用文件白名单。以后新增要分享的方法文件时，先明确加入 `.gitignore` 的允许项；不要强行把本地工作记忆加入版本控制。

## 什么叫“进化”

发现问题 → 修好当前成果 → 判断适用范围 → 更新对应方法 → 在后续实际工作中核对效果。记录仍待验证的效果，避免把“写进文件”说成“已经有效”。例如，把“一次简单铺垫太拖”总结为按信息量分配时长，不能总结成所有镜头统一三秒。

这套方法不训练模型参数，不运行后台扫描，不会自动收集其他人的聊天，也不保证从资料中找全所有信息。当前依据是 Sanjiu 的真实创作反馈；尚未完成多人试用验证。后续先积累各人的实际反馈，再按需要合并脱敏方法，处理适用范围和冲突，不以人数多少代替判断。
