# 创作方法

这些默认来自 Sanjiu 在脚本、短视频提示词和场景创作中的实际纠正。按本次需求使用，不把某一集的风格、参数或例外固定到所有作品。

## 先理解客户要改什么

- 分清细化、改编和重构。细化已有梗概时，保留关键事件、因果、角色作用与结尾；优化台词、表演、衔接和运镜，不擅自另写主线。
- 用户要求局部修改时检查关联位置，但不要借机重做无关场景、角色或已确认内容。区分客户明确要求、用户确认、助手提案和待核实资料。
- “简短一点”默认压缩措辞、无效重复和冗余内容，保留关键情绪的触发、变化与可见表演，以及已确认的因果和结尾。缩短文字与缩短成片总时长分开处理；必要停顿不一律视为冗余。能兼顾就直接修改，确需牺牲核心要求时才说明取舍并澄清。对应正反边界见 [修改与案例](修改与案例.md)。
- 当前任务的画风、画幅、时长、广告、字幕、声音及素材要求单独核对，不从旧片机械继承。续集还要检查人物当时知道什么。

## 写成可以执行的画面

- 动作交代视线、姿态、作用对象及先后衔接；表情呈现触发、变化和可见反应。用少量准确动作表现情绪，避免只写“震惊”“可爱”，也不堆微动作与形容词。
- 配角需要有在场理由和自然活动；能感知且与其有关的信息才引发相应反应，接话或行动应能影响对方或事情进展。保持人物知情范围，不把所有人写成同步惊讶，也不让配角只是排队走位、站着念词。
- 删去无助主线、互动或笑点的拿取、递交、收放等操作；必要道具保留并维持位置、数量和持物状态一致。
- 人物动作与环境变化有可见因果；提示词需要的运动不能只写抽象“震撼”“有冲击力”。
- 描述直接精简，少用“正常速度表演”等重复套话。夸张、写实、甜蜜或荒诞程度按本次内容决定。

## 让镜头与节奏服务剧情

- 在需要处写明景别、视角、移动和切换的目的：揭示信息、看清动作、交代关系或接住反应。时间分段不自动等于独立镜头，不固定三秒一切，也不机械堆推拉摇移。
- 台词、接话、动作、反应、镜头和转场一起估时。可同时完成的动作允许并行；先后发生的动作留足时间。保持时间段连续、分段合计符合要求。
- 不靠加快语速、无意义空镜、重复动作或时间标签掩盖超时。必要的情绪与笑点停顿保留；简单铺垫按信息量压缩，省出的时间用于新的反应和推进。
- 音乐可以持续，但不意味着长时间重复展示同一个动作。用户指定的关键台词与结构不能擅删，确实放不下时指出具体冲突并给出调整选项。
- 适用喜剧时，让人物目标、反差、误解与结果可见，结尾优先回收已有铺垫；不能为塞梗或专有名词破坏因果。其他题材不强套喜剧结构。

## 参考素材与声音

- 按用户编号建立人物、道具、背景与音色映射；角色更改后检查全文对应位置。参考已限定外形时沿用，别重复扩写或擅改造型；未收到的素材不写成已检查。
- 音色参考不是录好的对白；角色口播、歌曲人声、后期配乐和画面字幕分别处理。按本次要求决定生成什么，不能从“歌曲后期配”推出所有对白静音。
- 默认不另写音效清单、环境底噪和动作声音的文字描述，用户要求时补充。省略音效文字不等于要求静音；BGM按本次决定。
- 本地视频可读取时先实际检查再评价。可见字幕不等于音频转录，截图不能证明完整动作与声音效果。
- 引用官方设定、热度或原台词需要相应依据；二创和助手提案明确区分，不编造来源、热度或素材检查结果。

## 按用户要的层级交付

| 产物 | 默认写法 |
| --- | --- |
| 方向 | 核心创意、反差或作用，简短易比较 |
| 梗概／客户概述 | 讲清故事和关键变化，不塞入完整制作提示词 |
| 详细脚本 | 连续时间段，写动作、表情与必要运镜，角色台词另起一行 |
| 完整视频提示词 | 按下列六部分整合必要参数、参考与可执行画面 |

完整视频提示词默认结构：

【技术参数】

【镜头运镜】

【环境氛围】

【人物造型】

【核心动作/表演】

【声音/台词】

六部分仅用于完整视频提示词，不强套普通脚本；用户指定其他格式时遵从本次要求。每份独立生成提示词带必要上下文，不用“同上”替代。可复制成品默认纯文本，保留时间、标签和编号，少用装饰性标记；解释和未验证事项放在成品外。

## 真实反馈怎样变成方法

以下为去掉客户内容与具体角色后的摘要，并非可直接复用的客户脚本：

- 一次简单铺垫占时偏长：提炼为按信息量安排时间；不提炼为所有段落都应三秒。
- 已有梗概的细化过程中出现新主线：明确允许细化的范围，保护原因果；不冻结所有未来故事。
- 改变角色或素材之后旧编号继续出现：修改映射及全文关联位置；不把当次编号写进长期默认。

需要理解修改边界或选用历史范例时，按 [修改与案例](修改与案例.md) 核对前后稿、反馈和适用条件；不要把未被采用的候选、效果未检验的助手交付或被排除项目作为正确模板。
