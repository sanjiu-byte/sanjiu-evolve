# 独立模拟案例

16个合成案例，没有真实客户、项目、私人资料或凭据。

- inputs.json：执行代理使用。包含用户输入、初始文件、多轮与轮次间文件变动。
- rubrics.json：仅供检查代理使用。行为检查和关键失败条件独立存放。

每案建立独立沙盒，执行前后比较文件。测试写入只允许沙盒，禁止影响真实项目、账号或远程仓库。多轮之间保留本案文件；测试接续时应开新执行上下文，只加载待测规则、沙盒资料和当前轮输入。S07 不记测试允许当前回答含临时信息，但不允许主动写入持久化记忆；不能把宿主聊天自动留存错误归咎于Skill。

记录实际输出、读写路径和前后差异。不能只让执行代理说‘我会这样做’。未提供真实视频、图片、Word文件，因此这组测试只评估文本和流程，不证明媒体生成质量或真实多人长期效果。

检索案例只证明在给定小样本中找到了目标，不能证明任意规模资料中的零漏检。即使16案全部通过，也只能称这些场景模拟通过，不可称穷尽所有情况。
