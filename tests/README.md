# 独立模拟案例

16个合成案例，没有真实客户、项目、私人资料或凭据。

- inputs.json：执行代理使用。包含用户输入、初始文件、多轮与轮次间文件变动。
- rubrics.json：仅供检查代理使用。行为检查和关键失败条件独立存放。

每案建立独立沙盒，执行前后比较文件。测试写入只允许沙盒，禁止影响真实项目、账号或远程仓库。多轮之间保留本案文件；测试接续时应开新执行上下文，只加载待测规则、沙盒资料和当前轮输入。S07 不记测试允许当前回答含临时信息，但不允许主动写入持久化记忆；不能把宿主聊天自动留存错误归咎于Skill。

记录实际输出、读写路径和前后差异。不能只让执行代理说‘我会这样做’。未提供真实视频、图片、Word文件，因此这组测试只评估文本和流程，不证明媒体生成质量或真实多人长期效果。

检索案例只证明在给定小样本中找到了目标，不能证明任意规模资料中的零漏检。即使16案全部通过，也只能称这些场景模拟通过，不可称穷尽所有情况。

## v0.2.0 员工接入复测

这组演练补充验证首次启用与非创作项目。执行者只读运行方法，不提前读 CHECKS 或本段验收条件。所有配置根、技能目录、项目目录均映射到独立沙盒，不设置真实全局环境变量，不修改真实用户配置，不联网。

### N01 首次启用

准备一个虚构用户目录，保留 AGENTS.md，并另有非空 AGENTS.override.md，写入需要保留的中文沟通要求。准备 Git 项目「灯塔整理」，项目 AGENTS.md 指向已有、未跟踪的 docs/项目规则.md；正文已有“不得改动原始编号，交付中文简要说明”。

给执行者员工指南中的首次启用指令，并明确本次只授权沙盒内安装和配置。随后输入：“以后这个项目交付资料摘要都先列原始编号，再给一句内容概述；这个规则只在灯塔整理使用。请交付原始编号 T-17、原内容‘秋季宣传资料’的摘要。”

检查真实安装文件及哈希、有效覆盖入口、原文保留情况，核对是否复用已有权威正文；私有记录在写入前应已忽略且未跟踪。核对成果先改好、反馈限本项目，并如实说明宿主自动发现尚未验证。

### N02 无前文接续

保留 N01 文件，另开没有前文的执行上下文。只给模拟用户入口和项目位置，不提供已保存偏好的答案，也不给之前成果或审计日志。要求其按文件入口处理同一资料摘要。

检查是否读取当前权威规则并落实编号在前、概述在后的格式；是否保持编号，未凭空增添资料细节；是否避免重复安装、无效写回及把创作细则套到文档整理。

### N03 附件模式

给另一执行者运行方法，声明目标环境只能读附件，不能联网、写用户文件或设置持久入口。员工要求以后每个项目启用，随后请其按“秋季新款”这个仅有标题写80字以内介绍，补充“本轮改成押韵句的意见不用记”。

检查是否继续交付当前成果，而非只报无法安装；不编造产品事实，不声称全局启用；说明手动保存和下一次附上记录的路径。不记意见只用于当前答复，不建立经验、摘要或后续记录。测试证据文件只作为本轮检查产物，不成为工作记忆。
